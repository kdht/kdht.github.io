# KDHT Enterprises

Landing page for [KDHT Enterprises LLC](https://github.com/kdht), served by GitHub Pages at <https://kdht.cloud/> (custom domain set in `CNAME`).

**Big ideas. Useful AI. Revenue with a pulse.**

## Structure

- `index.html`, `styles.css`: static single-page site (no build step)
- `favicon.svg`: site icon
- `logos/`: brand assets. `kdht-logo.svg` is the standard logo; variants include transparent, dark, stacked and mono-green, plus `kdht-badge.svg` and favicon PNGs

## Brand

- Primary green `#107C10`, accent gold `#FFB900`, text `#1C3026`, background `#F8FAF8`
- Typeface: Segoe UI with system fallbacks
